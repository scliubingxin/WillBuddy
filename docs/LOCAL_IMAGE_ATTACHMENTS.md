# 本机图片与显式视觉输入 · 0.21.0

「添加图片」通过原生文件选择器导入PNG/JPEG；「本机图片」可再次选用或移除未被历史消息引用的图片。每次最多3张。默认只在本机保存/查看；明确勾选「发送图片给当前模型」才给本轮当前模型发送真实 `image_url: data:image/png;base64,...`。历史图片不在以后对话中自动重发；目标模型/地址在排队后变化则拒绝本轮，不静默换供应商或退化成假视觉回复。模型是否支持视觉由实际服务决定，界面不声称所有模型都能识图。

`services/images.mjs` 与原schema1增量 `imageAttachments` 保存规范化PNG，普通state仅下发ID/尺寸/名称，不含base64或SHA；预览仅通过独立图片IPC取有界bytes，再送到opaque媒体子帧Blob解码。无Node/原生桥，关闭释放objectURL；不加载任意file路径。导入端仅接受原生选择路径、拒绝符号链接、读取有界并复查，通过Electron nativeImage解码重编码为PNG。单图≤2MiB/4096边/4M像素，最多30图/总16MiB；普通用户无需另装软件。不是视频附件、转码或所有图片格式支持。

7项新核心测试覆盖格式/像素/大小、SHA、持久化、写失败回滚、串行导入、引用保护、原生适配器边界、明确视觉同意和模型变更。生产Chromium→真实服务/磁盘导入→PNG Blob实际decode→勾选→实际HTTP ChatCompletions image_url→刷新/磁盘重载通过。正常izer/原生选择器/IPC/模型语义为夹具；没有Mac nativeImage或实际视觉模型验收。首次浏览器测试的blob本地请求被误计为外网，后又误点侧栏搜索，已修正测试网络分类与历史任务定位并通过；不把这两项测试问题说成生产识图故障已修复。
