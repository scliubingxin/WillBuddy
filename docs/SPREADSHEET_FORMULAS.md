# Excel 公式与表格编辑 · WillBuddy 0.14.0

在成果中心创建或导入 XLSX，点击编辑内容。选择工作表，修改单元格类型与值；公式请明确选择“公式”类型，输入 `SUM(B2:B3)`。右侧即时预览依赖值，保存后生成新版本，下载得到真实 XLSX。工作表切换、只看公式、新增单元格不会丢失当前未保存输入。原文件不写回，前5版可导出。

AI 的 document_create/document_edit 可使用 `{ "formula": "SUM(B2:B3)" }` 单元格值，普通字符串 `"=SUM(B2:B3)"` 仍是文本。批准 document_read 后，完整有界 spreadsheetEditing 提供坐标、公式和计算值；结构超过12000字符不下发半截编辑结构。工具修改仍需原生逐次审批和版本校验，审计隐藏正文。取消、拒绝、冲突或磁盘失败不发布候选。

## 范围与边界

| 支持 | 限制 |
| --- | --- |
| SUM / AVERAGE / MIN / MAX / COUNT / IF / ROUND | 仅七个函数；无日期、查找、命名范围、动态数组、结构化引用或任意函数 |
| 算术、百分比、同类型比较、括号 | 文本算术和不同类型比较返回 #VALUE!；不承诺完整 Excel 类型转换语义 |
| 同表/跨表 A1、$A$1、矩形范围、带引号表名 | 无外部工作簿或网络引用；循环引用包括未选择 IF 分支也拒绝 |
| 数字/文本/布尔/错误缓存 | 错误结果按真实错误单元格保存；浮点计算，ROUND 位数仅整数 ±8；非精确财务计算 |
| 已有单元格样式与其他部件保留 | 不编辑格式/图表；带图表、透视表、结构化表格或数字签名的文件拒绝编辑 |

上限：10张表、5000既有单元格、1000公式，界面500单元格；每公式1000字符/300词元/256节点/64层；范围10000格，依赖深度200、100000计算步。共享/数组等带属性公式、未知函数和不合法行/坐标明确拒绝。文件原有导入检查与4MiB/解压上限继续生效。可以导入检查的文件不等于可以编辑的文件；含不支持公式或复杂派生对象的工作簿仅保留检查/导出原件路径。

## 架构

`desktop/src/shared/formula-core.js` 是主进程与页面共用的纯 JS 词法/AST/依赖图/求值核心，不使用 eval、Function、CLI、网络或模型执行表达式。`runtime/spreadsheet.mjs` 负责工作簿关系映射、严格坐标/类型校验和 OOXML 读写，保存时独立重算所有公式并写回 `<f>` 与有类型的 `<v>`。清除过期 calcChain、关系和内容类型引用，要求 Office 打开时再次计算；即使最后一条公式替换成常量也清理旧链。主进程不信任页面提供的计算结果。

保留既有单元格样式引用、样式表和未触及 ZIP 部件；修改的工作表 XML 会重序列化，不宣称 ZIP 字节不变。原 Web/Python未切换到此引擎，跨端完整业务核心仍未统一。已有 GenOffice HTML→DOCX 子引擎保持；本轮没有引入 GenOffice 完整电子表格引擎。
