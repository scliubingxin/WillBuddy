# PPT 图层定向编辑候选 0.37.33

批准读取 PPT 后返回每页顶层图形/图片的对象 ID、坐标、哈希和受限内容；调用 document_edit 的 pptLayer 提交一个带 anchor 的变更，并经过已有审批、版本及摘要检查。支持页面内位移、缩放、置前/置后和 RGB 纯色填充；图片保持原比例。签名包、含对象动画的页面、组合对象、无效几何及未知操作拒绝。其他 ZIP 部件的解压字节保持，目标页 XML 会重新序列化。

本地独立三页合成样例包含多层卡片、图片和表格；实际生成和图层修改后由 Linux LibreOffice 转 PDF 并检查画面，python-pptx 检查对象。模型调用使用本机 HTTP 夹具，审批模拟。当前没有直接拖拽图层的用户界面；没有验证 Mac、PowerPoint、真实模型、真实用户文件或动画播放，不能称复杂模板全面保真。

验证记录：Node 串行相关测试 85 项通过（包含实际本机 HTTP 模型协议夹具、审批拒绝、旧对象与文件版本保护、其他 ZIP 部件 SHA 对比）；scripts/tests 35 项通过。Office 外观样例为合成英文数据，已实际渲染检查；不等于真实 Mac 或付费模型验收。
