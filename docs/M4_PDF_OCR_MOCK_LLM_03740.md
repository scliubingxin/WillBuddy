# M4 多页PDF OCR与mock LLM检查点

模型可请求 pdf_ocr 对用户已授权目录中的PDF识别连续1至5页。源文件打开与权限/SHA反复校验，16MiB、100页PDF上限、每页1600px、有限输出和超时；先批准再调用固定可信OCR与Poppler路径，整个批次成功才返回带页码/文件SHA的文字。临时目录私有，过程失败或中断清理；识别内容只用于工具结果，审计隐藏正文，提示可能有误。PDF与OCR程序仍以用户权限运行，不是OS沙箱。

真实Linux系统Poppler和Tesseract处理合成英文扫描两页、来源变更时不返回部分、权限撤销与审计测试通过。Apple芯片可执行文件及中文语言数据未打包，Mac端当前会报告未内置；不是PDF附件上传或全格式理解。

模型批量工具调用全部预解析并验证ID和参数后才执行首个，流式工具调用缺少完成状态不会执行。以HTTP mock模型验证错误第二调用不会导致首项副作用，且无隐式重试。109项相关Node测试和35项打包测试通过；模拟模型和部分原生桥不是付费模型/Mac验收。
