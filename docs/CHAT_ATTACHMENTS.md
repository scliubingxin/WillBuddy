# 对话附件问答

当前输入区入口：「＋ → 上传文件或 ZIP」；模型与思考强度在右侧模型菜单。详见[对话输入区](COMPACT_COMPOSER.md)。

点击对话输入框的 **上传附件**，通过系统选择器逐份选取 DOCX、XLSX、PPTX、Markdown、TXT、CSV、JSON 或 HTML。附件卡片可预览、移除。输入问题后点击发送，当前模型收到所附文档的实际提取正文，无需开启智能体工具；仅选择文件不会联网调用模型。图片沿现有“添加图片”入口，像素仍需明确勾选发送。

本机导入副本保存在成果中心，不修改原文件；TXT/CSV/JSON 按UTF-8纯文本作为Markdown资料副本保存，文件名保留原扩展名。一次最多5份（含目录资料），正文合计最多10万UTF-16字符；单个副本沿既有4MiB/解压32MiB/10万提取字符与100文档/16MiB空间限制。超限明确失败，不静默截断Office正文。原目录文件摘要仍沿原有截断标识。

发送时只传documentId/revision/SHA，主服务按真实副本字节重验并提取；不信任渲染层提交正文或名称。排队删除、修订变化、二进制篡改或目标模型/地址变化时阻止发送。每次后续模型轮次也重验。原始附件内容不额外存入聊天正文；对话保留名称、版本、SHA引用。后续轮次不自动重发附件正文，可点击历史卡片“附加当前版本”重新选择；这是当前保存版本，可能不同于历史版本，发送前可预览。模型先前回答仍可能含资料内容，会按原聊天历史规则进入后续请求。移除输入框卡片不删除已导入副本或服务商已接收内容；需在成果中心删除副本。

原生选择即授权导入这个文件的副本；界面提示发送正文给当前模型，点击发送授权本轮该副本资料发送。它不授予原目录权限、其他文档读取或工具审批，也不复用知识检索授权。文件被视为不可信资料，不能因附件中的指令擅自执行操作。

DOCX/PPTX/XLSX复用已有有界解析器，回答依据文字/单元格与公式缓存，不保证完整排版、图表、图片、页眉页脚或全部对象提取。PDF、旧DOC/XLS/PPT、扫描件OCR、压缩档、视频/音频上传本轮未实现；不能把图片型文档当已识别。空提取结果明确拒绝。HTML作为文本资料；脚本不在模型准备阶段执行，预览仍沿既有隔离策略。
