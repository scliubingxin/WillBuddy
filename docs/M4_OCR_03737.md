# M4 OCR 工作检查点

仅识别本轮明确附加的PNG图片：校验字节和SHA、原生批准、私有临时目录，调用受信任的固定Tesseract可执行路径，限制语言、时间与输出，识别后再次核验图片及取消状态，删除临时文件，审计不存正文。返回源图片ID/SHA和文本，提醒核验。

Linux 使用实际系统 Tesseract 和合成英文图片通过；模型与审批为测试夹具。应用将只从固定内置路径寻找OCR引擎，目前 Apple ARM64 引擎及中文数据均未随包分发，所以目标Mac目前会明确失败。PDF逐页、表格OCR及多模态视觉仍未实现。

保留可选本机 Ollama 向量链路，需用户自行提供服务和嵌入模型；本机服务可能联网。73项相关测试通过，真实嵌入语义模型、Mac原生、进程池与压力性能尚未验收。
