# Word 格式完成通知与真实 DOCX 验收

本轮从权威 WillBuddy 0.37.14（读取时版本53）重新取得完整ZIP，核验765个内容文件SHA-256后开发。没有从旧main接续。

`office_format_selection` 原有字体、西文字体/东亚字体、字号、字色和字符底纹现在复用原生 `postUnoCommand(..., notifyWhenFinished=true)` 完成通知。每个固定命令必须收到对应名称和布尔结果；相同属性的false完成结果只能说明命令已结束，不能代替成品验收。没有新增任意UNO入口。

新增无Electron的 `runtime/office-word-format.mjs`：将真实选区文字唯一对应到正文连续段落及UTF16字符范围，允许原生保存拆分run，核对覆盖的每个文字片段均含批准的直接属性（ascii+hAnsi、eastAsia、半点字号、RGB字色/底纹）。另核对正文、页眉、页脚全部段落文字及顺序。原生未执行、只执行部分属性、缺一个CJK run属性、字号错误或原文变化均不能发布新revision。旧标题加正文全选可跨连续纯文字段落，不能为简化验收退回单段限制。

只接受唯一可映射的简单正文选区；重词歧义请选更完整文字。域、链接、图片、制表符、段内换行、修订/内容控件等复杂目标保守拒绝；2000段/10万文字/选区12000 UTF16字符。目标段可位于普通表格，但不是整表属性编辑。没有解析样式继承、字形是否存在、版式/图片/批注/脚注/母版或全部OOXML关系，不承诺任意Office无损往返，也不把XML属性写入称为Mac中文缺字已解决。

审批前后和持久running审计后重新绑定selection/sequence/revision/SHA/取消/30分钟许可；最后一次异步画面查询后再检查取消与版本。worker独立比较expectedSelection，错误选区不发格式命令。开始native调用前置dirty和输出核验器：部分native失败仍保留受验收约束的草稿；显式保存重试不能绕过核验，未保存草稿阻止新AI格式操作。文档磁盘写入失败仍保留旧持久版和可重试草稿。保留原审批、审计脱敏、CAS和每请求一次修改额度。

这不是原生原子事务：部分修改、取消或保存失败可留私有草稿；完成审计失败不能撤回已保存版本。不自动重放命令，撤销可能需要多步。既有Word结构编辑、Excel七函数公式/常量/格式、PPT精确替换、原Web/Python、身份和白蓝logo均保留。
