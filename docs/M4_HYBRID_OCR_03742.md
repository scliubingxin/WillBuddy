# M4 混合检索与OCR检查点

本机嵌入配置启用时，对经批准文本分别计算向量相似度和词法召回，通过倒数排名融合并去除重叠片段；各结果保留版本/SHA、原文、位置及召回来源。模拟嵌入不保证真实模型语义质量，本机服务也可能自行联网。无本机模型时不会冒称本地语义能力；旧词法模式保留。

多页OCR逐页保留结果和页码；无识别文字的页明确标注不能证明原页为空，不丢弃前后页。实际测试使用Linux Poppler/Tesseract和合成英文三页；Mac引擎、中文模型、PDF附件直传与真实用户原件仍未验收。

114项相关Node测试通过；模型语义映射为夹具。M4未完成，本包为内部源码检查点，不要求用户安装。
