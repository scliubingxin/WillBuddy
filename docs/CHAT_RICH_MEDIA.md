# 0.20.0 对话富媒体

对话及 Markdown 阅读视图现在能展示图片、视频、网页链接卡片，以及真实数值驱动的柱状图、折线图、饼图。均随 WillBuddy 安装；无需 GenOffice、Office、npm 或额外播放器。

## 用法

图片使用 Markdown `![图片说明](https://cdn.example.com/image.png)`，或普通 HTML 的 `<img src="https://...">`。先显示标题、来源域名及「查看图片」，点击才请求媒体。可展开、收起、关闭；加载失败有重试提示与原始链接。

视频使用 `[演示视频](https://cdn.example.com/demo.webm)`，也支持 MP4/OGV 直链或 `<video src="https://...">`/`<source>`。点击「加载视频」后使用内置控制条播放、暂停、拖动进度、调音量；不自动播放。实际解码测试为合成 WebM/VP8，不代表所有视频编码兼容。YouTube、B站等播放页是网页链接，不冒充可直接播放的视频文件；DRM、登录、无跨域许可或网络受限的直链可能无法加载，提供明确错误和打开原始链接。

网页使用 `[资料标题](https://www.example.com/report)`。独占一段时显示卡片及域名，行内链接仍为超链接。点击走既有内置浏览器及审批链路；不会为生成卡片抓取网页、元数据、favicon，亦不执行网页脚本。

图表用完整的 `chart` 代码围栏：

```chart
{"type":"bar","title":"示例数据 · 月度收入","labels":["一月","二月","三月"],"series":[{"name":"收入","values":[12,21,18]}]}
```

`type` 为 `bar`、`line`、`pie`。多系列最多4组、标签最多30项且每组数值长度一致；数值必须有限且绝对值不超过1e12。饼图仅一组非负数、合计大于零。每条消息最多6张图，每张JSON最多24000字符。图表标题、图例和「查看图表数据」表格保留实际值，不靠模型生成图片。未闭合的流式围栏保持代码；不合法数据展示源代码和原因，不伪造图形。模型指令说明此语法并要求数据有来源、示例标示；未做真实付费模型验收。

## 实际边界与隔离

- 本轮为**展示**能力，不含本地图片/视频附件导入、文件上传、视频转码、视觉模型识别或通用图表编辑器。
- 外部媒体只允许无凭据的公开 HTTPS URL；拒绝 file/data/blob/javascript/http、非443端口、字面IP和本机域名；URL过滤并非域名解析防火墙。原始内容中的脚本、事件、用户SVG、iframe、应用data-action、自动播放均被净化。
- 外部图片/视频在单独 opaque iframe 中运行，仅 `sandbox=allow-scripts`，无same-origin、Node、preload、原生桥、表单、弹窗、嵌套帧、worker、fetch连接权限。CORS anonymous 和 no-referrer；需要服务器允许匿名跨域。主界面与 Office 预览原有网络策略保持，只有固定媒体页面可请求HTTPS图片/视频。
- 安装包通过固定 `/media/index.html`、`/media/frame.js` 路由供给本机受信代码；资源SHA-256加载前核对。不是任意文件/URL代理。经典IIFE脚本避免 opaque frame 中模块脚本的跨域启动失败。
- 父子消息同时检查frame来源、随机token、类型，单次初始化；5秒组件启动、15秒媒体加载超时；不隐式重试。最多同时3项媒体，一条消息最多12项。关闭、切任务、原文变化或销毁会终止会话；后台重绘且消息未变时保持原frame。不是跨重启自动加载或跨文档缓存。视频流由浏览器按需加载，无任意大小媒体离线归档承诺。
- 图表是自主生成的有限 SVG 图元及可访问数据表，用户不能提交SVG/JS回调、URL、任意图表插件；原始回复/Markdown导出不变。现有 Office、HTML 静态预览、浏览器许可、CLI、双任务、兼容加密身份和原 Web/Python 保持。
