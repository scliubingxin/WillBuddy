# LibreOfficeKit 预览池实验检查点

可在模型设置勾选实验性Office预览复用，重启后生效；默认关闭。每个私有进程用独立profile，一次只打开一个经现有格式门禁验证的文档，完成PDF导出后调用LibreOfficeKit document destroy，确认清理协议后才复用。队列最多2进程，空闲60秒关闭；取消、协议错误、进程失败及超时关闭实例，不自动重放。单任务文件私有暂存并清理，原文件及用户数据不改。

真实Linux LibreOfficeKit测试连续六次交替导出两份文档、DOCX/XLSX/PPTX完整路径与错误输入，测试文本无交叉；独立真实Node子进程测试重置、超时取消与迟到工厂/销毁，卡住假worker测试取消后无残留。一次测试冷启动315ms、第二次30ms，仅环境样本。85项相关Node测试、35项打包测试通过。不能保证对任意复杂文档跨文件无泄漏或物理擦除，Mac LibreOfficeKit版本/中文字体/签名/并发未验证。

本地嵌入服务和OCR代码继承先前候选：没有随包的嵌入模型、Apple OCR和中文数据，PDF多页OCR未实现。完整M4尚未完成。
