# WillBuddy 0.10.1 授权弹窗修复

用户截图实际显示document_create报告创建确认框：0.10.0将整份JSON结构传给macOS原生sheet，内容超长把按钮挤出屏幕。已改为文件名/大小/SHA256+前400字符人类可读摘要。读取文档的确认也只显示摘要；大批修改超过600字符时要求拆分，不隐藏未展示的替换参数。所有原生确认超过1000字符或20行直接拒绝，不打开超大弹窗；macOS textWidth=500。正文仍经批准后保存到成果中心预览。

旧approver只在调用前后检查取消信号，没有传入Electron dialog。新版给有父窗口的异步showMessageBox传AbortSignal；取消/60秒超时/应用退出会中止等待，迟到的允许不会生效。拒绝无父窗口确认，避免macOS退回同步且不可取消的对话框。如果原生层取消后仍未关闭，后续操作直接报错，不叠加新弹窗。菜单「取消所有操作确认」及⌘⇧Esc可紧急取消；工具页也有取消入口。旧包当前卡住可先Esc取消，不用降低系统安全设置。

浏览器首次原生确认有三项：取消、允许这一次、本任务本站点允许。第三项是显式同意：仅绑定当前runId和准确scheme/host/port，可打开、读取、检查、点击、填写，可能触发网页提交；非默认选项。任务完成、退出、撤销后失效，不持久化。新任务/新站点重新确认；已知跨站链接或跨站formAction仍逐次确认，网页跳转后读取需新站点许可。浏览器检查/点击/填写原有快照、单次动作凭证和遮挡保护不变；系统浏览器不共享该授权；CLI/文档不自动授权。所有操作仍审计授权来源，输入正文脱敏。

工具页/菜单可撤销所有浏览器任务授权，同时关闭待确认弹窗。持久化等待期间撤销会阻止真正执行；网页读取前后检查地址及导航epoch，防止旧站点许可返回跳转后正文。瞬间撤销不撤回已经发生的点击/已发送资料。

验证：105核心测试（新增9项授权生命周期/权限边界/长报告/导航竞态），6项真实Chromium回归。原生弹窗通过注入dialog适配器测试，不是Mac真机窗口高度或快捷键验收。官方API依据 https://www.electronjs.org/docs/latest/api/dialog/ ，signal关闭异步消息框，macOS无父窗口时不可用。离线包仍ad-hoc未公证、Mac严格签名/启动未验收。
