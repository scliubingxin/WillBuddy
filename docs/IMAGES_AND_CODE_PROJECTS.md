# 图片和代码项目

在输入框＋选择添加图片，PNG/JPEG原图最多32MiB/64百万像素。应用本机自动缩放后显示缩略图；勾选本轮发送图片再提问，也可不输入文字直接发送。较大照片会缩小细节，原件不改。最多8张，发送失败保留草稿供手动重试。HEIC/WebP/GIF尚不支持。

代码ZIP可从上传文件或ZIP导入，支持的正文继续用于问答；完整运行项目独立保存。打开＋→代码项目与运行环境，或直接在此导入。先查看文件与实际脚本，再逐项准备依赖、构建/测试或启动。npm项目识别package.json的dev/start/build/test；Python支持venv、requirements和main.py/app.py/server.py。多个根或依赖缓存目录请先整理。导入不会运行代码或联网。

第一次执行授权私有工作目录，每一条CLI还需系统确认。依赖安装可能联网，使用当前系统账号权限，工作目录不是OS沙箱。npm安装默认忽略安装脚本，明确启动的包内脚本仍执行。日志、退出码、停止按钮在工具台命令队列；刷新仍在，重启暂停/中断，不自动重放审批。源码变化或路径变链接阻止新执行，重新导入后再审阅。

WillBuddy主程序无需npm安装；运行你上传的npm项目需要你本机已有npm/Node开发工具，Python项目需要Python3/venv/pip。未内置这些工具的安装器。每次运行最长5分钟、输出最多1MiB，适合准备环境、测试和有界本机试运行；尚非生产长驻部署系统，不自动部署外网，不提供容器/系统依赖/端口代理或秘密环境变量配置。

项目最多10个，压缩包32MiB/2000条目/展开16MiB/单文件4MiB。完整运行项目与问答32份正文/10万字符预算独立；看到运行项目不表示模型读过所有代码。项目副本持久保留，目前无删除UI。外部执行可能已产生副作用，停止不能撤回远端请求。

测试：真实npm/Node HTTP健康响应和停止、Python虚拟环境/空依赖安装/入口实际执行；浏览器使用生产页面与真实服务，原生选择器/IPC/确认为夹具。nativeImage缩放为注入适配器测试；没有Mac或实际付费视觉模型结论。
