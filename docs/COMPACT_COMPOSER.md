# 对话输入区

默认只显示输入区与一行操作栏。

- 左侧「＋」：上传文件或ZIP、添加图片、本机图片、授权资料；需要时设置工具开关。
- 智能体：选择本轮角色，原来的 `/` 快捷选择仍可使用。
- 右侧模型：选择快速/均衡/极致或指定模型和思考强度；完整配置入口在菜单内。
- 发送按钮：Enter发送、Shift+Enter换行，执行时仍可独立停止。

图片发送确认只在有图片附件时显示，默认不勾选。文字附件在点击发送后交给所选模型。收起菜单不等于撤销附件或改变权限；审批与原限制继续有效。

菜单可用Tab和Enter操作、Esc关闭并回到触发按钮；点击外部或移走焦点关闭。未主动操作菜单的同任务后台重绘保留打开状态/焦点/草稿，切换任务关闭。菜单按窗口空间显示并可滚动。窄屏工作区保留覆盖层行为，应先关闭覆盖层再操作输入框。
