# M4 进程池工作检查点

通用隔离池以固定容量排队，执行成功后仅在适配器明确返回重置成功时复用；失败、取消、超时或重置失败销毁实例，不自动重放。关闭会取消活动任务并等待迟到工厂销毁。真实Node子进程测试PID复用、先前数据清除、失败重置、取消与关闭。

尚未连接现有每进程单文档 LibreOfficeKit worker，未测其析构或跨文档隔离，不能声称Office热池或加速。真正接入前需用目标LibreOffice验证其对象销毁稳定性与内存/文档隔离、冷/热性能及Mac原生环境。

本检查点包含前一向量和OCR候选：本机Ollama嵌入需自行运行服务，真实模型未验收；Mac OCR可执行文件和中文数据未打包。总计78项相关测试通过。
