# 本机语义向量检索工作检查点

设置中填写本机 Ollama 嵌入模型后，绑定知识检索先逐份请求文档读取批准，再确认将正文和查询送到127.0.0.1:11434。通过 /api/tags 固定模型摘要，/api/embed 批处理生成并归一化向量，按余弦排名并返回原始来源、行号和坐标。状态及配置漂移、响应格式错误、取消拒绝返回；存储失败恢复。索引为可反推内容的敏感派生数据，普通 state 不含向量，清除索引会清理；不保证底层磁盘物理擦除。服务可能自身联网，本应用不证明其隔离。
