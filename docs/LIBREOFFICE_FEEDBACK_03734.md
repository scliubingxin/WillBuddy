# LibreOffice 方案与用户反馈：0.37.34 候选

附件提出独立 Agent 与 LibreOffice 文档工具、UNO 操作、模型工具调用等分层；现有产品已有独立 LibreOfficeKit 工作进程、标准工具循环、选区/版本保护。本轮继续复用，未引入 OXT 插件或开放新的网络服务。

- 普通域名后台打开不再弹窗，保留审计；读取及交互仍使用原权限。IP、本地域名和系统浏览器仍需批准。域名判断不是网络隔离或 SSRF 防护，DNS 解析目标未检查。
- 模型 fetch 故障按错误代码返回 DNS、连接、超时、TLS 或通用提示；不泄露原始错误和凭据，不隐式重试。用户截图里的具体根因未确认。
- PPT 默认正文按中英文字符估算密度并设置明确字号、中文字体名、顶端对齐及自动换行；复杂文字、实际字体回退和不同渲染器仍可能溢出。

改动在 Node 真实执行和 OOXML 字节层验证，原生审批及模型使用夹具；并非 Mac 用户原始文件或网络环境验收。

验证：相关 Node 测试 86 项通过，涵盖新截图反馈、浏览器导航/审批、模型配置、PPT 图层和 Office 选区；模型和原生审批部分为夹具。一次旧测试期望网页打开总是拒绝，与新授权策略冲突，调整为检查本地地址仍需批准后全量相关回归通过。

打包脚本测试 35 项通过；Mac 原生签名和安装尚未验收。
