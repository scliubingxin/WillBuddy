# PPT选中文字的手动修改（0.37.22）

用户反馈0.37.21字体候选解决了其截图中的字体问题；不推断所有字体或文档均已通过。

PPT普通文本框选中文字后可点击“编辑选中文字”，编辑框载入原文字并绑定选区与sequence，保存时复用真实内核选区、页面、版本/SHA守卫和原生输出校验，保留其他页文本及已支持的直接格式。手动点击是该操作授权，不重复AI审批；写前审计仍必须成功。失败不清除输入，取消可放弃草稿。错误的英文IPC包装在指定场景转换为中文提示。

当前仅支持唯一、普通、单段、同直接格式的文字选区与最多600字符单行替换；复杂对象、多段、重复歧义、格式级联仍拒绝。不是完整PowerPoint直接键入/IME/拖拽或万能格式保真。截屏中的原始文档未提供。

涉及desktop/services/office-workspace.mjs、main/office-windows.mjs、office-preload.cjs、src/office/office.js与index.html及测试；保留0.37.21 fontconfig候选。用户已报告字体改善，但没有独立Mac原件/签名/Gatekeeper验收。
