# WillBuddy 0.10.0 文档工作台

## 使用流程

1. 在成果中心的「文档工作台」选择「导入文档」，从原生文件选择器导入 DOCX/XLSX/PPTX/Markdown/HTML。原件不会被写回。也可直接在对话中要求「创建一份Word方案，含目标、步骤和预算表」，保持工具模式开启。
2. 模型通过 `document_create` 生成真实文件包。原生审批展示内容结构/原文、格式、大小与SHA-256，批准后保存本地文档。仅回复文件名不算创建成功。
3. 「AI 修改」将文档ID加入新任务草稿。模型先调用 `document_read`，你批准后它得到提取文本和版本号；再调用 `document_edit`。原生窗口展示查找/替换或单元格修改，新版本通过文件解析与哈希核验后保存。
4. 「精确修改」可手动提出同一组修改，走相同审批/版本服务。「预览」查看提取文字，md支持Markdown，html可切换既有隔离静态HTML预览。预览不是Word/PPT保真排版。
5. 「导出文件」通过原生保存窗口选择位置。字节先在目标目录独占暂存、fsync，再发布、回读比较。旧版本可在「历史版本」中导出。不要将导出对话框取消当作下载完成。
6. 一个任务执行时仍可点击「新建任务」开始另一项；两项共享模型执行容量，更多任务排队。切换原任务可独立停止或继续写草稿，不会停止其他任务。后台数量显示在顶栏，状态与队列在任务页。

## 已实现范围

| 类型 | 生成 | 修改导入/已有成果 |
| --- | --- | --- |
| DOCX | 标题、一级标题、段落、可编辑表格 | 段内文字替换，支持跨Word文本run；页眉页脚文字也处理，其他ZIP部分逐字节保留 |
| XLSX | 多工作表、文本/数字/布尔/空单元格，常量文本不会当公式执行 | 指定sheetN.xml编号+地址更新常量，保留目标样式编号和其他部分；含公式工作簿暂拒绝更新 |
| PPTX | 白蓝主题、标题/项目符号、讲者备注 | 幻灯片段内文字替换，保留其他包内部分；不修改讲者备注 |
| Markdown/HTML | UTF-8原文 | 精确字符串替换，保持原文其余内容；HTML只在现有sandbox静态预览中显示 |

Word/PPT替换的新文字继承匹配起始run的样式，不保证所有复杂格式或布局完全一致。Office导出格式使用docx 9.13.0、pptxgenjs 4.0.1、fflate 0.8.3、@xmldom/xmldom 0.9.12，以及受限XLSX OOXML写入器。构建时预打包至runtime/vendor/office.cjs，附16个实际打入模块的许可和哈希。最终用户不安装npm、Python或Office来生成这些基础文件。

## 数据、权限和故障

沿用schema1，增量增加 `documents` 数组。当前版含id/name/format/revision/sha256/size/text/base64，前5版的原始字节保留在history。原模型密钥/加密身份不迁移。文档内容与旧对话一样保存在本机工作空间JSON中，不是文档加密保险箱。渲染进程的普通state只提供文字、版本、哈希等摘要，不下发二进制或历史正文；模型工具对话收到文档名称/ID/格式/版本目录，读取正文仍需单独确认。

同一文档的提交串行化并检查 expectedRevision，审批期间另一项任务改动会失败，要求重新读取/审批；不会覆盖他人的新版。审批凭证只能使用一次、绑定私有候选字节，不接受界面提供的伪造回执。保存失败回滚内存候选；开始提交前取消不保存。若取消发生在已发布/已提交之后，已产生的文档/文件仍保留，不自动删除或重放，请以版本与实际文件为准。

单文件4MiB，解压前检查中央/本地目录、路径、重复、大小，最多2000条目、单条8MiB、总32MiB；解压后CRC、XML、格式根部件再次校验。宏、嵌入对象、ActiveX、DTD/实体、外部关系链接拒绝导入。Office结构输入100000字符、Word区块200、Excel10页/每页1000行×50列、PPT50页。文档空间最多100个/总16MiB（包括base64与历史），满时拒绝写入，需先导出所需版本后清理。

## 实际验证与差距

测试使用真实编解码器/临时文件/Store与HTTP模型协议夹具，生成及编辑的DOCX/XLSX/PPTX分别经独立python-docx、openpyxl、python-pptx打开，核对段落、表格、单元格、幻灯片与备注。浏览器测试加载生产页面，经真实服务生成、修改、导出DOCX，并发两项实际HTTP请求并独立停止，检查任务草稿。原生桥、对话框与审批为注入适配器；模型内容为夹具。不是付费模型、Mac原生、Microsoft Office/WPS或页面保真验收。
