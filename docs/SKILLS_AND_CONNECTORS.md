# 技能上传、连接器与智能体绑定 · 0.22.0

2026-10-24。根据用户六张配置截图，把能力管理从智能体内的手工文本扩展为可复用的 Skills 技能库与 MCP 连接器。沿用 WillBuddy 蓝红logo/白蓝主题；不复制截图中的账号、密钥、其他产品资产或虚构技能市场/连接器目录。

## 入口与操作

智能体页面顶部提供「智能体 / Skills 技能库 / MCP 连接器」三页签。

- 技能库：上传 SKILL.md 或技能 ZIP、查看正文与文件目录、启用/停用、删除。被智能体引用时须先解除绑定再删除。
- MCP连接器：添加/编辑名称、简介、Streamable HTTP地址与启用状态；「测试连接」经批准实际 initialize/tools/list，显示上次发现的工具及其简介，可取消。测试不调用业务工具，也不把历史发现状态伪装成实时在线。
- 新建/编辑智能体：知识文档、已上传 Skills、一般工具白名单、MCP客户端、提示词与ReAct轮数分区配置。勾选绑定的能力后保存，不复制整份技能资源到每个智能体。
- 构建中可直接「上传 Skill」或「配置新的 MCP / 保存连接并选中」，原名称、提示词和已有选择保留；迟到的上传结果不能写入后来打开的另一个智能体表单。
- 原0.21手工技能/内嵌MCP仍在折叠区域中保留、可编辑。旧记录无需迁移、不会清空。

## Skill 包范围与边界

支持单个 `.md`（规范化入口为SKILL.md），或根目录/单层包目录中有唯一 `SKILL.md` 的ZIP。参考 [Agent Skills 格式说明](https://agentskills.io/specification)（2026-10-24读取），读取name/description及Markdown正文；支持简单单行/引号/折叠或字面多行描述，附加metadata保留在原文，不作执行配置。当前是有界格式子集，不是完整YAML解析器；复杂YAML标签/别名/流程对象不作语义解释。名称≤64字符、描述≤1024，入口全文≤12000字符；保留原始入口正文，不切半篇发送。`allowed-tools`不增加权限，仍由智能体白名单与原生审批决定。

ZIP上传≤4MiB，中央目录在解压前检查：最多128条目/64实际文件、单个256KiB、总展开2MiB；拒绝路径穿越/盘符/反斜杠、大小写重复、符号链接、加密、目录冲突、CRC/大小错误、额外根。复用有界ZIP编解码器；Mac AppleDouble旁车不存储。所有文件仅存内存记录，不解压到文件系统、不安装依赖、不自动执行scripts。技能库40项/总展开16MiB。

普通state只下发元数据和文件目录，不含正文/base64。模型初始只见技能目录，通过 `skill_read(name)` 按需读取完整SKILL.md及资源目录；`skill_resource(name,path)`仅能读取该智能体绑定包内的UTF-8资源，≤12000字符、精确路径与SHA检查，禁止包外路径/未绑定包/二进制渲染。二进制assets可有界保存但本轮不提供模型视觉或导出执行；脚本文本可以阅读，不会由资源读取器执行。

## MCP 配置与执行

连接器保存不联网。测试连接、任务连接和每次业务工具调用分别按原生策略审批。保存的工具发现结果仅作历史展示，任务运行会重新发现，不能只凭上次目录冒称成功。测试最多同时2项，支持取消、退出取消；审批期间编辑/停用即阻止启动请求，配置变化或取消后的迟到结果不保存。失败、保存失败、被拒绝均显示真实结果，不能执行业务工具。

仍是0.21的真实Streamable HTTP客户端：HTTPS或本机HTTP，无URL凭据/查询/fragment；15秒/1MiB/工具目录限制、JSON或SSE响应与会话清理。**暂不支持API Key/自定义认证头、OAuth、stdio或旧双端点SSE**；例如需要账号密钥的商业服务不能仅靠截图里的URL完成连接。不读取或复用截图密钥，不用演示状态掩盖缺账号。

## 持久化、运行与兼容

schema1增加 `skillPackages` 和 `mcpConnections`，agent增加 `skillIds/mcpIds`。保存失败回滚，技能包不可原地替换（上传新版本后明确重新绑定）；全局连接修订号递增。任务按绑定ID解析能力，配置/停用/删除变化使后续请求或工具调用失效；不会扩大现有原生文件、浏览器或CLI权限。两任务队列、原Web/Python、Office/HTML预览、图片与旧系统身份保留，无新安装端依赖。
