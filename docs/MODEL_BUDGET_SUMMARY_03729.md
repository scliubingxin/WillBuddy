# 模型轮数上限与阶段性结果

对话启用工具时（配置至少两轮），最后一轮保留给模型整理本次已有观察；不提供工具定义，不重放工具，也不增加模型请求次数。模型须说明已知来源、未完成事项和不确定性。服务把这一结果标记为阶段性并保存，任务状态仍标为未完成；下一条消息可在既有历史窗口内看到该总结。若模型在整理轮仍返回工具调用，则拒绝执行并保留执行记录。取消仍阻止迟到结果。单轮设置沿用原限制行为；Office 专用对话不启用此策略。

这不保证模型一定能生成总结，失败、超时或模型不兼容时仍显示错误；不是自动重试或恢复完整工具上下文。轮数和 Token/费用是不同预算。模型和原单模型设置已有 1–96 范围及继承显示，仍可由用户修改。截图中的 Office 临时 worker 校验修复沿用此前候选，但用户 Mac 原始故障原因尚未确认。
