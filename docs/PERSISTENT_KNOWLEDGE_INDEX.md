# 持久词法知识索引

智能体的 knowledge_search 现在可在本机保存并复用词法倒排索引。首次获批查询构建，后续查询和应用重载后复用；文档改版、提取文本变化、规范化语言环境或索引算法变化会触发重建。它不是向量语义检索、OCR、全盘搜索或自动后台扫描。

## 用法与权限

- 按原方式在智能体绑定知识文档并启用工具。每次查询仍逐份批准 document_read；全部读取成功且版本未变后才接触索引。索引不缓存审批、不免除文件读取、不允许查询未绑定文档。
- 结果仍提供原文片段、版本/SHA、LF行号和UTF-16偏移；来源卡片与旧单文档参数兼容。没有命中不证明事实不存在。
- 在智能体页面点击「清除检索索引」可清除本机索引，文档、历史来源卡片和对话不受影响。后续获批查询会重建；清除不会停止已在运行的任务，之后的获批查询仍可能重建。
- 删除或更新文档后，旧索引不能用于当前查询；下次获批查询会清理失效记录。这不是后台文件监听、立即磁盘安全擦除或云端同步。

## 实际索引与复用

`runtime/knowledge-index.mjs`只负责纯文本倒排构建和候选选择；`runtime/knowledge-search.mjs`复用同一分块、原文匹配、排名、覆盖报告和完整JSON预算；`services/knowledge-index.mjs`只处理Store适配、来源校验、持久化与串行更新，无Electron依赖。

每个块约1000 UTF-16字符、约200重叠，保留原边界和行号。对NFKC/大小写处理后的文字建立字母/数字/下划线的单字和相邻双字倒排表，查询使用各词的前1–2字筛选候选，再在本次已批准原文上执行原有完整子串匹配和排序。因此中文、单字、全角英文、英文词中间子串和非BMP字符不会因改用精确整词索引而漏召回；候选只是超集，不能据索引构造片段或确认事实。

持久条目包含文档ID/revision/文件SHA、完整提取文本UTF-16 SHA、语言环境、块坐标、倒排表和结构校验和；不保存查询或额外正文副本。倒排词项仍是敏感资料的衍生内容，随既有私有workspace.json按600权限保存，普通state投影明确移除，模型结果只收到索引构建/复用/候选数量摘要，不收到倒排表或全库目录。

载入的条目经版本、提取文本摘要、几何、结构与SHA校验后才复用；通过校验的内存条目深冻结并按对象引用记为已验证，避免重复序列化整份索引。源文本摘要与元数据每次仍核对。校验和用于检测损坏，不是对恶意改写本机工作区并重算摘要的签名防护；没有把本地缓存称作认证边界。真正的读取边界仍是智能体绑定、原生批准及当前文档。

## 上限、故障与取消

- 每次最多8份绑定文档、每源10万UTF-16字符，沿用现有读取范围；画布提取不完整仍明确提示。
- 每条持久索引≤2MiB，最多16条、合计≤8MiB UTF-8 JSON，按插入顺序清理最早条目。超过字典50000键、150000块引用或2000000规范化字符预算时，当前文档不缓存，明确计入uncached并执行原有完整扫描，不截断搜索范围。
- 多任务共享一个Store级串行写队列；独立查询不会互相覆盖索引字段。每份文档前让出事件循环并检查取消/配置/所有来源版本；不是无界CPU任务，也不承诺逐毫秒取消。
- 拒绝、撤销、取消、来源改变、存储失败不会返回本次片段。保存失败恢复旧内存字段；写入成功后发现取消/来源变化，会尝试恢复旧字段并再次保存。若回滚也失败，明确报错、不返回片段，下次查询仍须重新审批并校验；不声称抵御掉电或磁盘硬件故障。
- 清除索引也经同一队列，保存失败恢复旧字段。该操作没有任意路径删除能力；主帧IPC门禁不变，没有新增免审批索引读取接口。
- 包括索引摘要和旧单文档source封装在内的完整工具JSON保持≤30000字符，必要时移除最低排尾片并标resultLimited，不截断JSON。

## 验收证据

280项核心（新增16项）、4项相关真实Chromium、9项打包Python通过。新增覆盖扫描结果逐项等价、跨重载复用、中文/全角/英文中间子串/单字/非BMP、35次固定种子混合文本查询、源revision/SHA/提取文本变化、损坏/未知版本/畸形行重建、超限全文回退、16条和8MiB预算、清除保留资料、写失败回滚、写入后取消的磁盘回滚、冻结、并发合并、暖索引再次拒绝仍不返回，以及完整旧单源JSON预算。

合成约7.6万字符资料的真实Node Store实验：96个源块中仅2块进入完整匹配评分；首次构建2条，Store重新加载后复用2条、重建0条，匹配内容与坐标相同。它是候选数量实验，不是端到端时延或Mac性能承诺；批准读取、文本哈希和几何核对仍然存在。

生产Chromium+实际本机HTTP模型6轮：Skill→资源→两份真实Markdown查询（构建2）→第二次查询（复用2）→带Bearer的MCP→回复。磁盘重载后真实文档改版仅重建预算索引、复用另一份；真实按钮清除后原资料/对话保留，模型请求不增加。原生IPC/审批、系统密钥与模型语义为夹具，不代表Mac/付费模型/企业服务验收。
